**MIMICRIA** is a Python application designed to inspect Roblox avatar profiles, extract equipped asset IDs, and generate executable commands to mimic their outfit in-game.

подходит для использования как на **Windows**, так и на **Linux**.

---

## 🚀 Функционал

* 🔍 **Анализ инвентаря:** Быстрое получение списка надетых предметов любого игрока по его Username / UserID.
* ⚡ **Генерация команд:** Автоматическое создание готовых команд для смены скина в игре.
* 🖥️ **Графический интерфейс:** Удобный GUI, написанный на PyQt6.
* 🐧 **Кроссплатформенность:** Полноценная поддержка Windows и Linux.
